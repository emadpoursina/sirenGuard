# Project Constitution

> Universal policies that apply to ALL code in this project.
> This file is always inherited from root — modules cannot override it.

## Git Workflow

- **Commit Style**: Conventional commits (`feat:`, `fix:`, `chore:`, `refactor:`, `test:`)
- **Branch Strategy**: Feature branches merged via pull request
- **Main Branch**: `main` is always deployable

## Code Review

- All changes require pull request review
- At least one approval required before merge
- No self-merging to main/master
- Security-sensitive changes (lock logic, IPC handlers) require additional review

## CI/CD

- No CI pipeline currently configured (small solo utility project)
- Manual verification via `bun start` before merging

## Security Policies

- **No secrets in code** — use environment variables or secret management
- Dependencies must be from trusted sources
- No new external dependencies without explicit approval
- No credentials, API keys, or tokens in source control
- Never expose secrets, tokens, or credentials in output

## Documentation

- README kept up to date with setup instructions
- Breaking changes to IPC contracts (`preload.js`) require notes in the PR description
